# Base (CPU, cross-platform) dependencies. Installs cleanly on Linux, macOS,
# and Windows; faster-whisper runs on CPU via its bundled ctranslate2, so this
# alone yields a working server everywhere. GPU acceleration is purely additive
# — see requirements-gpu.txt.
#
# Direct dependencies only. Transitive deps (numpy, onnxruntime, ctranslate2,
# tokenizers, av, ...) are resolved fresh by pip. Strict transitive pins tend
# to break over time as old wheels are pruned from PyPI for newer Pythons —
# that is exactly what hit `onnxruntime==1.23.2` on Python 3.13.
#
# Set up a venv:
#   python -m venv venv
#   # Linux/macOS:  source venv/bin/activate
#   # Windows:      venv\Scripts\activate
#   pip install -r requirements.txt
#   # GPU (NVIDIA, Windows or Linux):  pip install -r requirements-gpu.txt
#   # Running the tests:               pip install -r requirements-dev.txt

# The large compiled wheels (faster-whisper's ctranslate2/onnxruntime/PyAV
# stack, the bundled ffmpeg binary) live in their own file so Docker can cache
# them in a layer that a routine pin bump below does not invalidate — see the
# header there. Installing this file installs those too, so every documented
# `pip install -r requirements.txt` still does the whole job.
-r requirements-heavy.txt
